# 加拿大补助库（大多伦多 · 小企业）

把散落在省/市政府网站上的补助项目，整理成**中文、可筛选、带截止日**的索引。
每天自动更新，免费、免注册、不用装 App。

## 现在收录什么

| 来源 | 层级 | 内容 |
|---|---|---|
| 安省 Available funding opportunities | 省级 | 省内各厅的资金项目（状态/截止日/资格） |
| 多伦多 Business Grants & Incentives | 市级 | 市级补助、返款、代金券 |

> 正式版会补：皮尔区 / 约克区 / 荷顿区，以及联邦 BBF（需浏览器渲染，单独处理）

## 页面能力

- 中文标题 + 中文摘要（英文原名保留）
- 筛选：层级 / 状态（仅看开放）/ 适合谁（默认只看小企业可申请的）/ 金额区间
- 搜索：项目名、机构、关键词
- 每条标注**核对日期**与**官方原文链接**

## 设计原则（比功能重要）

1. **宁缺勿错**：金额只在「up to / maximum / per project / grant of $X」这类明确句式下才展示。
   「项目成本区间」和「基金总规模」绝不当作补助上限——错一个数字比不写更糟。
2. **只做索引不做镜像**：不复制申请条款，永远链到官方页面。
3. **受众分类**：市政/警察/院校/原住民团体/非营利的项目会被标记，
   默认不在「小企业可申请」视图里出现，但保留可查。

## 本地运行

```bash
python3 fetch_grants.py     # 抓取 + 结构化 → data/programs.json
python3 build_site.py       # 生成网页   → docs/index.html
open docs/index.html
```

设 `GEMINI_API_KEY` 才会生成中文；不设也能跑（页面为英文）。

## 目录

```
fetch_grants.py        抓取 + 解析 + 受众判定 + 可选翻译
build_site.py          生成单页站点（筛选/搜索都在前端）
data/programs.json     结构化项目库（入库，保留历史）
data/changes.json      与上一版对比的变更（新增/截止日变化/状态变化）
raw/                   抓取快照（不入库）
docs/                  发布产物（不入库）
```

## 数据准确性与免责

本项目只做索引与摘要。金额、资格、截止日期以政府原文为准，
页面上每条都有一键直达官方的链接和核对日期。**申请前请务必点开原文核对。**

## 想改某个项目的「归属」？（不用碰代码）

筛选里的「对象 / 状态」都是数据驱动的。如果发现某个项目归错了：

1. 打开 `config/audience.json`
2. 在 `overrides` 里加一行：项目名片段 → 桶名
   ```json
   "Starter Company": "business"
   ```
3. 桶名只有六个：`business`（小企业）/ `nonprofit`（非营利）/ `gov`（机构、协会、院校）/
   `indigenous`（原住民组织）/ `mixed`（多方均可）/ `unknown`（未标注）

判定顺序是：**人工覆盖 → 原始 Recipient type 列 → 资格原文关键词**。
多伦多那 28 个项目有官方 `Recipient type` 列，直接按它判；安省 22 个逐条核对过资格原文，
写在 overrides 里。新抓到的项目会先走自动判定。

## 每条项目的「官方页面」是怎么定的

不把用户丢给搜索引擎（那样点进去是搜索结果，等于随便给一个页面）。三级解析：

| 顺序 | 做法 | 覆盖 |
|---|---|---|
| ① | 抓项目块里**它自己**的官方链接：`ontario.ca/page`、`ontario.ca/document`、`forms.mgcs.gov.on.ca` 的 Program Guidelines、TPON 申请页 | 15 个安省项目 + 28 个多伦多项目 |
| ② | 按标题猜 `ontario.ca/page/<slug>`，**并用页面标题校验**（实词覆盖 ≥60% 才用） | 偶尔命中，宁缺勿错 |
| ③ | 都没有：官方资金页 + 文本片段 `#:~:text=项目名前几个词`，浏览器自动滚到那一条 | 7 个安省项目 |

两条硬规则：

1. **每个链接上线前都做一次可达性检查。** Ontario Grants Portal（`grants.gov.on.ca`）已停用，
   官方页面里还留着旧链接，直接给用户就是 502 死链——现在会被拦下并降级。
2. **没有独立页面就明说。** 卡片底部写「官方原文 · 定位到该条」，详情里注明
   「该项目在安省官网没有独立页面」，并给出**官方咨询邮箱**（从同一页面抓取），
   而不是拿一个相似页面糊弄。
